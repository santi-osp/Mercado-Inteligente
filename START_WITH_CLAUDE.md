# Prompt inicial recomendado para Claude Code

Después de copiar este paquete a la raíz del repositorio, puedes iniciar Claude Code con un mensaje tan simple como:

> Lee `CLAUDE.md` y `PROJECT_MANIFEST.md`. Tu tarea es ejecutar `GOALS_MASTER.md` completo del GOAL-01 al GOAL-10, actualizando `PROJECT_STATE.md`. No te detengas al terminar un goal individual. Si falta una credencial o acción externa, marca esa sub-tarea como `BLOCKED_EXTERNAL`, continúa con el resto y solo finaliza cuando hayas recorrido los diez goals y cumplido la Definition of Done global.

No es necesario volver a pegar los goals en el chat: están dentro del repositorio.
