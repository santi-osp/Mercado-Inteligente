# Referencia de prototipo visual

Archivo: `assets/prototipo-ui.png`

La imagen es una referencia de dirección visual, no un pixel-perfect contract. La especificación escrita UI/UX tiene prioridad cuando haya diferencias.

Rasgos a conservar:

- sidebar claro;
- dashboard orientado a datos;
- verde primario sobrio;
- cards con poca sombra;
- métricas legibles;
- “Mejor opción” como foco;
- estrategias alternativas;
- comparación por producto;
- freshness/capability badges;
- responsive móvil coherente.

No copiar logos reales de retailers como requisito; texto/nombre es suficiente.
