# Acciones humanas externas pendientes

Estas tareas pueden requerir al usuario y NO deben bloquear el resto del roadmap.

## Google Maps Platform

- crear proyecto Google Cloud;
- habilitar facturación si se solicita;
- habilitar Geocoding API;
- habilitar Routes API;
- crear/restringir API key;
- configurar quotas/budget alerts;
- ingresar la key a Mercado Inteligente mediante UI/SecretStore.

## OpenRouter

El usuario ya dispone de API key con saldo.

Cuando corresponda:

- ingresarla mediante Settings, no editar archivos versionados;
- elegir modelo;
- ejecutar Test Connection;
- configurar límite/funciones opcionales.

## Validación física de precios

Cuando la app esté suficientemente avanzada, opcionalmente registrar 5–10 productos D1 y Éxito con EAN/precio online/precio góndola/fecha para medir concordancia. Esta validación mejora confianza pero no bloquea el desarrollo.
